# Crelan

Crelan helps teams deploy and manage applications on Kubernetes from a workspace, the CLI, or an existing CI pipeline.

- [Open Crelan](https://crelan.abj.pipeops.app)
- [Customer documentation](https://crelan.abj.pipeops.app/docs)

Choose an available cluster, browse workspace resources, deploy a public GitHub repository or an existing container image, and manage the resulting application. Secret values are not displayed in the workspace.
