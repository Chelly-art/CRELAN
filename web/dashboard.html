AUTOMATION & CI/CD

Continuous deployment setup

Integrate your CI/CD pipelines to build and deploy applications automatically.

1. GitHub Actions (Official Action)

Save CRELAN_TOKEN in your repository secrets and CRELAN_API_URL in variables:

name: Deploy to Crelan
on:
  push:
    branches: [ main ]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: ./.github/actions/deploy
        with:
          api-url: ${{ vars.CRELAN_API_URL }}
          token: ${{ secrets.CRELAN_TOKEN }}
          app-name: storefront
          port: "8080"
2. GitLab CI / Any CI Runner (Image Deploy)

Build and push your container image in CI, then instruct Crelan to roll out the image:

deploy:
  stage: deploy
  script:
    - curl -X POST "$CRELAN_API_URL/api/v1/deployments" \
        -H "Authorization: Bearer $CRELAN_TOKEN" \
        -H "Content-Type: application/json" \
        --data "{\"name\":\"storefront\",\"image\":\"$CI_REGISTRY_IMAGE:$CI_COMMIT_SHA\",\"port\":8080}"
