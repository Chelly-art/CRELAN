SERVICE TEMPLATE

Self-host Infisical

Setup guide for deploying Infisical with Crelan services.

Guide only

Attach prerequisites

  1. Create a PostgreSQL database in Databases.
  2. Create a Valkey service in Services & storage. Infisical documents Redis; verify Valkey compatibility with the version you deploy.
  3. After resources report ready, save their connection URLs as external connections and attach them to the Infisical app.

Required app configuration

Infisical needs a database connection, a Redis-compatible URL, a stable ENCRYPTION_KEY, and AUTH_SECRET. Losing the encryption key can make stored secrets unrecoverable. Official setup also recommends HTTPS and a pinned image version.

Example image: infisical/infisical:latest-postgres
Generated values stay in this browser and are not sent to Crelan. Save them securely; they cannot be recovered here. Generation does not configure the app.

            

            
Guide only; no one-click deploy. You can attach saved connection secrets from an app’s details, but Crelan does not automatically provision the full Infisical configuration or add required environment settings. Generate and save the keys, store database/cache URLs as connections, then map them to the exact environment variables expected by your pinned Infisical release. A ready database or cache alone does not make the app highly available.

            
Reference: Infisical’s self-hosting guide · configuration and key guidance
