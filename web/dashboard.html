SERVICE TEMPLATE

Self-host Infisical

Prepare a pinned Infisical image deployment and connect workspace services.

Setup flow

1. Prepare the services

  1. Create a PostgreSQL database in Databases and wait for it to be ready.
  2. Create Redis or Valkey in Services & storage. Infisical requires Redis; Valkey compatibility is not guaranteed by Infisical, so use Redis where available or verify compatibility yourself.
  3. Save each ready service as a workspace connection with a connection URL. The app details page can attach CONNECTION_URL as DB_CONNECTION_URI or REDIS_URL.

2. Deploy and configure the app

Infisical’s official Docker guide requires ENCRYPTION_KEY, AUTH_SECRET, DB_CONNECTION_URI, REDIS_URL, and SITE_URL. The app details flow stores the two keys as Kubernetes Secret values, sets the public URL, and attaches database/cache connection keys by reference.

infisical/infisical:v0.166.8

Deploy the app first. Open its details to apply Infisical configuration after the workload exists. You will need ready PostgreSQL and Redis/Valkey connections.

Deployment prerequisite: create PostgreSQL and Redis/Valkey first. After deploying the pinned image, configure it from app details. The UI applies settings and connection references; it does not claim an HA guarantee. Valkey compatibility with Infisical is not guaranteed by Infisical.

Official references: Docker deployment and required variables · pinned v0.166.8 release · Infisical setup walkthrough
